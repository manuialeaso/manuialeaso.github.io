# 抗性新制、鈍擊與屬性溢出

程式：`afk-resist.js`（開關 `resist`，需要核心補丁 31、32）、`afk-stun.js`（開關 `stunfix`）、`afk-rebirth.js`。

## 火／水／風／地屬性抗性（你、傭兵、怪物受到的屬性傷害都一樣）

| 抗性 | 受到的屬性傷害 |
|---|---|
| 0 | +50% |
| 50 | 正常 |
| 100 | -20% |
| 150 | -30% |
| 200 | -40% |
| 250 | -50% |
| 300 | -60% |
| 400 | -70% |
| 500（上限） | -80% |
| 500(+100) | -85% |
| 500(+200) | -90% |
| 500(+300) | -99% |
| 500(+500) | 屬性傷害免疫，改當成物理傷害計算 |

- 表中兩點之間依比例內插（例如抗性 25＝+25%）。
- 面板超過 500 時顯示「500(+X)」。
- 屬性免疫時：怪物的屬性一般攻擊照純物理流程算；屬性魔法改吃無屬性抗性的物理減傷百分比。
- 怪物也套這張表：抗性 0 的怪物受到屬性魔法 +50%，負抗性一樣算 +50%。怪物抗性到 500(+500) 時改吃牠無屬性抗性的物理減傷比例。

## 無屬性抗性（減物理傷害）

在整個物理傷害公式算完、百分比減傷特效（合計上限 75%，你和傭兵都是）之後才套用：

- 每 1 點減少 1 點傷害（最多算 500 點），最少還是會受到 1 點。
- 另外依門檻再減百分比：100＝1%、200＝3%、300＝5%、400＝7%、500＝10%、500(+100)＝15%、500(+200)＝20%、500(+300)＝25%、500(+400)＝30%、500(+500)＝減 20% 再減 20%（共 36%）。
- 無屬性魔法照舊吃原本的無屬性抗性折減。

## 鈍擊

- 單手鈍器的武器效果「鈍擊」（你和傭兵）：命中後目標暈眩 1 秒，100% 無法行動。
- 對頭目有效的只有鈍擊：頭目 50% 免疫；沒免疫時 50% 機率時間減半，再 50% 機率時間再減 30%。其他技能的暈眩照舊對頭目無效。
- 任何怪物連續暈眩 10 秒 → 完全停擺 15 秒：不行動、不回血、不放技能，副本的定時技能也停。

## 六屬性溢出（轉生角色）

- 屬性上限 200；裝備、Buff、血盟等其他來源超出的部分，仍算進近戰、遠程、魔法的傷害、命中、爆擊與額外魔法點數。
- 面板顯示「200(+X)」。
