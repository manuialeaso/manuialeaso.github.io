# 轉生技藝：實作說明與近似處

程式：`afk-arts.js`（開關 `arts`，排在 afk-rebirth 之後）。測試：`/root/bench/arts-test.mjs`。

## 共通規則

- 轉生後到燃柳村找 **奧拉奇里亞** 免費學習；每職業兩門，二選一（可回來免費改選）。
- 免死各自獨立：席琳的永生（遺物，30 秒）、不屈命運（HP<50%，每場戰鬥一次）、絕望身軀（HP<30%，每場戰鬥一次）。
  其他免死（命運迴響「絕望身軀後每場戰鬥免死一次」）共用 30 秒冷卻。
- 「一場戰鬥」＝場上持續有活著的怪；換地圖或 5 秒沒有怪就算離開戰鬥。
- 攻速上限：面板顯示 0.1 秒，實際 0.5 秒一擊、每擊傷害 ×5（等於每秒 10 擊）。
- 四大天王：轉生角色帶傭兵時，上場人數每 4 人全隊普攻追加 1 次（16 人＝5 次）；追加攻擊＝武器最大值（大小傷取大＋強化值），不觸發特效。
- 16 人上場：傭兵的技藝效果（倍率、減傷、能力加值）減半。
- 傷害加成與減傷用「攻擊前後 HP 差」補算，所以會跟其他所有加成相乘。

## 近似或尚未做的地方

| 項目 | 目前做法 |
|---|---|
| 16 人時傭兵「精通」減半 | 未做：精通在程式裡是開／關，沒有強度可以減半。目前只減半技藝。 |
| 闇龍追隨者「龍騎士精通效果 ×2」 | 併入「所有傷害 ×3」，沒有逐項加倍精通。 |
| 妖術師「幻術精通傷害 ×2」 | 做成所有傷害 ×2；「魔力精通效果變 50%」未做（原效果不是數值）。 |

| 百般武藝「龍的一擊」 | 遊戲沒有這招，定義為：一般攻擊 15% 機率追加本次傷害 ×3。 |
| 致命創傷 | 命中後 5 秒內，全隊一般攻擊對該目標 +20%。 |
| 席林眷屬「黑豹不限一隻」 | 程式裡找不到黑豹限制，未做。 |
| 席林／殷海薩眷屬的命中、抗性加成 | 只做了傷害與減傷（每擊 ±(WIS+INT)×1.2）；命中與抗性未做。 |
| 融合魔獸 | 20 隻合成 1 隻（HP 加總、傷害 ×20），沿用原召喚物外型。 |
| 無神論者 | 四屬性五階五星魔法每 3 秒一輪（威力 ×3），不是每次攻擊，避免卡頓。 |

| 王族魔劍技藝 | 原本 10%／20% 之外再補 37.5% 機率，合計約 50%；吸血鬼之吻只有玩家本人會施放。 |
