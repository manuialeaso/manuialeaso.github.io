# 七城攻城、城堡收成、宣戰與統一伺服器

程式：`afk-castlewar.js`（開關 `castlewar`），核心補丁 27。測試：`/root/bench/castlewar-test.mjs`。

## 城堡

- 七座城都能攻：肯特、風木、海音之外，新增奇岩城、妖魔堡、侏儒城、亞丁城。
- 新城沿用前三座的兩階段攻城：外門區打城門 → 內城打守護塔 → 獲勝進城。
- 城門、守護塔複製樣板城，HP 加成：奇岩、妖魔堡 ×1.2，侏儒城 ×1.3，亞丁 ×1.6。
- 背景圖（`assets/area/1920x1080/` 下的 12 張）用專案裡既有的美術重組，依各城的特徵挑選：
  - 妖魔堡：木柵欄圍起、裡面是茅屋（外門區＝妖魔森林、內城＝木造城郭、城內＝茅屋村落）
  - 侏儒城（地底城）：蓋在地下洞窟裡（外門區＝大洞穴、內城＝地下洞穴城牆、城內＝地下石殿）
  - 奇岩城：石造大城（外門區／內城＝石城調色、城內＝奇岩城鎮廣場）
  - 亞丁城：王都（外門區＝護城河城門、內城＝王座大廳、城內＝亞丁王城廣場）
- 打下的城一直保留，最多 7 座。遊戲本身只記得最近打下的那座當「主城」（城堡傳送、商店 8 折照舊用它）。
- 持有的每座城都會出現在所屬地區的地圖清單裡：妖魔堡放在歐瑞、侏儒城放在龍之谷。

## 收成（每小時，同模式所有角色共用）

| 持有 | 每小時 |
|---|---|
| 3 座以上 | 500 萬天幣 |
| 5 座以上 | 500 萬天幣＋100 龍之鑽石 |
| 7 座（統一伺服器） | 1,000 萬天幣＋100 龍之鑽石＋100 席琳結晶 |

- 收成在遊戲開著時結算，一次最多補 72 小時。
- 天幣進目前登入的角色。

## 宣戰

- 持有 1 座城：沒有血盟對你宣戰。之後每多 1 座城，對你宣戰的血盟 +2。統一伺服器：所有 NPC 血盟都對你宣戰。
- 宣戰中殺敵對血盟的人不會變紅。
- 狩獵時場上強制有敵對血盟 NPC（夢艷地獄也是：王＋敵對 NPC）。
- 敵對 NPC 是王族時，5% 機率呼朋引伴，場上出滿 5 名敵對玩家（夢艷地獄：王＋4 名）。
- 敵人強度依連續擊殺數提升（死亡歸零）：

| 連續擊殺 | 強度（相對於你本人） | 一次幾人 |
|---|---|---|
| 0–99 | 原本的敵對玩家 | 1 |
| 100 | 40%（全身 +3） | 1 |
| 500 | 40% | 2 |
| 1000 | 55%（遺物 +0） | 2 |
| 1500 | 55% | 3 |
| 2000／3000／4000 | 65%／75%／85%（遺物 +5／+10／+15） | 3 |
| 5000／6000／7000 | 85%，減傷 10%／20%／30% | 3 |
| 8000 | 93%（昇華支配 +0），減傷 30% | 3 |
| 9000 以後 | 100%（你的影子），減傷 30% | 3 |

- 強度＝你本人的 HP、平均每擊傷害、AC、MR、命中、攻速，乘上上表的比例。減傷用加 HP 換算。
- 精通與技藝沒有逐一複製，影子的能力用你目前的實際數值代表。

## 統一伺服器

- 連續擊殺 1 萬名敵對血盟 NPC，全體血盟投降、宣戰結束。你死亡時擊殺數歸零（強度階段也一起從頭算）。
- 統一期間敵對 NPC 不掉任何東西；在夢艷地獄中照常有機會掉遺物（原本的 0.001%）。
