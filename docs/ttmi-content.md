# 天堂透視鏡內容補齊（套裝、變身、地圖）

資料來源：天堂透視鏡 www.ttmi.me（2026-10-22 讀取）。名稱轉成繁體；透視鏡沒有、或本作沒有對應系統的部分另外說明。

## 套裝（afk-sets.js，開關 `sets`，核心補丁 34）

- 新增：反王、賽尼斯、火焰之影、泡水（頭具／帽子／頭巾）、暴走的變異、屍魂、營養滿分、懷念的骷髏／侏儒／歐西斯、活動飾品套裝（慈愛、奇蹟、希望、幸運、熱情、真實、11 週年白／黑／紅、修練者）。
- 新首領：反王肯恩 Lv75、賽尼斯(首領) Lv72（傲慢之塔 41~60 樓）；變異實驗體 Lv89（魔族實驗室 2 樓）。
- 火焰之影：炎魔謁見所的炎魔鐵匠製作，素材由象牙塔 4~8 樓與暗影神殿 3 樓的火焰之影掉落。
- 泡水（原作釣魚）改由伊娃王國、海賊島地監與水邊怪物掉落；屍魂（原作屍魂塔分解）改由不死系首領掉落。
- 懷念的套裝：原版部件掉落處 1/5 機率；活動品：所有首領 0.05%（暗夢星迴除外）。
- 沒做：妖精套裝（透視鏡沒列部件）、修好的飾品（只有水中呼吸）。
- 圖示：`python3 scripts/gen-set-icons.py`（用既有圖示改色，可重跑，日誌 logs/gen-set-icons.log）。

## 變身（afk-polys.js，開關 `polys`）

- 道具變身 Lv52：拉曼斯、安迪斯、艾迪爾；日出之國 Lv52：侍、陰陽師、大名、姬武者、忍者
- 特殊死騎 Lv80：闇黑／雷霆／黃金／焚焰死亡騎士；90 級卷軸：格利特、特羅斯、伊詩蒂、喬、絲莉安
- 變形控制戒指專用：墮落的司祭、歐姆裝甲兵、亞克騎士、生日慶祝妖精（近攻／遠攻／魔法）
- 速度換算：攻＝每分鐘攻擊次數（依武器）、走＝1440÷值、有向施法＝600÷值 tick、硬直秒數×10 tick（單手劍欄）。
- 沒做：占星術（透視鏡不給讀取）、服裝變身（沒有攻擊速度）。

## 地圖（afk-maps.js，開關 `maps`）

- 資料：`data/ttmi-maps.json` → `node scripts/build-ttmi-maps.mjs` → `afk-maps-data.js`。
- 37 張：亞丁地區、風龍棲息地、龍之谷地監7樓、強盜出沒地、獨眼巨人出沒地、闇龍的傷痕、密林地帶、墓園、海底隧道、死亡廢墟、亡者之墓、高崙研究所、侏儒部落、冰之女王的宮殿、象牙塔(火焰之影)、暗影神殿1~3樓、北島、妖魔部落、蜘蛛森林、黑騎士前哨基地、荒地、修練地監1~4樓、慾望洞穴、水／火／地／風之領域、炎魔房間、魔族實驗室1~2樓、船舶之墓、地底湖。
- 已有的同名怪物直接沿用；沒有的 153 種用外型相近的既有怪物當樣板（借動畫與掉落），數值依等級換算。
- 透視鏡等級是重製版的，每張地圖用一個係數換成本作等級帶（json 的 `k`）。
- 沒加：透視鏡上沒列怪物的地點（魔法師研究所、伊娃神殿、奇怪的村落、妖魔內城、隱藏之港、天空之園、屍魂塔等）。

## 卡片收集（2026-10-22 改）
- 新地圖的怪併進原本所屬的收集地區（歐瑞、亞丁、奇岩、古魯丁、海音、說話之島、風木、燃柳、龍之谷），不另開一組；反王肯恩、賽尼斯(首領) 併進傲慢之塔。原地區要完成就得連新怪一起收。
- 卡片一樣有一般到鑽石各階，掉落與轉蛋規則照原本卡片系統。

## 支配者傲慢之塔（2026-10-22）
- 透視鏡的新版傲慢之塔只有 1~10 樓＋頂樓，做成 11 張地圖「支配者傲慢之塔1樓～10樓、頂樓」，地圖選單在「傲慢之塔」後面獨立一組，跟原本 100 樓的傲慢之塔分開。
- 怪物等級照透視鏡（Lv70~89），全部新做，不共用舊塔的怪；跟既有怪物撞名的加「(支配)」（例：恐怖的火炎蛋(支配)、邪惡的鐮刀死神(支配)）。每層都有首領「鐮刀死神的監視者」。
- 卡片收集獨立一區「支配者傲慢之塔」，79 種怪；集滿加成為額外傷害，各階數值與傲慢之塔同一組。
