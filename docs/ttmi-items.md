# 天堂透視鏡物品：實裝、來源與平衡

本文件記錄「一般裝備、材料、補給與角鬥戰場道具」擴充；遺物各階段設計與 GM 道具由遺物文件另列。

### 掉落查詢、小百科與收藏

「怪物／掉落查詢」現在可搜尋全部新增物品，物品詳情直接讀本作的售價、NPC、893 條工坊配方及材料用途。材料用途可點進成品；大量配方折疊顯示，沒有刪掉較後面的配方。古物商人使用實際固定售價，不會顯示原生一般商店的攻城八折；裂痕補給只列場內戰勳兌換。

同一份來源 API 供小百科使用，另可查 20 張高階變身卡及 3 種補償券／碎片。合成文字讀取正在執行的成功率、材料數與保底次數，不另外維護一份容易過期的數字表。

可取得且符合原生分類的新增內容，載入時就加入收集冊分母，不必先拿到一次，也不會重載後消失。新增 1,094 件裝備、1,115 件道具，另補入接用的 24 種龍素材；13 件寵物之牙按其裝備欄位歸入寵物裝備，10 種箭矢依原生規則不列入裝備冊。這會調整既有滿冊玩家的完成百分比與完成加成門檻，**既有收藏紀錄不刪除**。

裂痕補給與戰勳取得時依原生 `gainItem` 登錄道具冊；離場只清除本場庫存，曾取得的收藏紀錄仍永久保留。3 種高階卡補償券／碎片歸道具冊；20 種高階變身歸自己的永久卡片收藏，不重複占用一般道具冊分母。沒有來源、未實作的箱內物品與 GM 道具，不會因本擴充而加入一般收藏要求。

遺物特殊規則也會依「遺物合成」及「重複遺物帶詞綴」開關即時更新，已移除「遺物數值永遠固定」的舊說明。重新開啟查詢會讀取當前狀態，無須重新整理網頁。

### 停用後的存檔保護

「亞丁古物與材料工坊」停用時，物品定義、收藏分類與已取得的背包／倉庫內容仍保留。原生讀檔會清理沒有定義的物品，因此這些資料必須在開關關閉時照常登錄。

停用會撤下新增 NPC、307 種怪物上的 697 筆新增掉落，以及 893 條工坊配方的可用入口；新增消耗品與工坊交易不能繼續操作，額外能力依開關停用。再次啟用會恢復內容，重複開啟不重複登錄。裂痕同一場切換開關不重領進場戰勳，離場清理即使在停用狀態仍執行。收藏分母不因切換開關改變。

原始來源配方保存在產生資料的 `recipes` 中；**本工坊額外加收工資**，所以畫面金幣需求可能高於透視鏡。工資補至至少「成品定價 ×37.5% ×產量」，已有金幣需求高於此數時不再加收；原料提煉維持固定 100 金幣。`ttmiServiceFee` 獨立記錄新增工資。

本工坊產出不附帶祝福、古老、屬性詞綴；既有其他 NPC 製作規則保持原樣。這項適配使配方金幣成本高於白板成品的 30% 回收價，避免「購買新增材料→製作→賣出」直接製造金幣，也避免反覆製作刷詞綴。不要把帶有珍貴詞綴的物品當成本工坊材料；可先鎖定。

生命之葉復原採本作確定產出的製作方式，**沒有宣稱原版成功率為 100%**。透視鏡未公告的復原機率沒有填入臆測數字。原料提煉則提供材料的穩定用途，並形成額外金幣消耗。

配方註冊前檢查所有材料及成品是否存在、材料數量是否為正整數、是否形成循環；缺一個材料就不登錄整條配方。這一版沒有因循環而拒絕的配方。

## 補給、裝備與戰鬥計算

- **治療藥水**：有確切補量的物品使用來源區間；轉生 ×3 走原生 `potionHealBase`，因此是抽到的補量乘 3。這一層不把所有一般藥水改成 10 秒冷卻；10 秒最低冷卻屬於本輪另外實作的遺物治療效果。
- **短藥水冷卻**：依來源秒數記錄，HP 與 MP 藥共用原藥水冷卻，不能用舊藥水繞過新藥水的冷卻。遊戲每 0.1 秒更新，0.53 秒最快在第 6 個更新點可再次使用。
- **料理、一般增益、經驗補給**：各有自己的增益類型，同類後用者取代前用者。來源加速一／二／三段有相應機制，純移動加速不增加攻速；同段移動加速取較強者。
- **百分比 HP／MP**：例如 +20% 會按上限倍率處理；和既有靈魂昇華取較高效果，不會誤作固定 +20 或重複堆疊。
- **強化門檻**：同一個能力只採符合條件的最高門檻，例如 +5／+7／+9 的減傷是逐級取代。不同欄位仍各自對應自己的門檻。
- **抗性**：新增昏迷、寒冰、石化、睡眠、支撐抗性加在原有那次判定，不額外擲一個獨立機率；石化／麻痺、緩速／束縛依本作既有狀態類型對應。
- **寵物裝備**：分別接寵物命中、物傷、AC、MR、智力、精神及魔法傷害流程。寵物經驗倍率只作用於穿戴的那一隻，同時穿兩件取較高倍率。沒有本作對應基礎屬性的寵物物品留在待補清單。
- **法術卷軸**：引用專案已有的真實技能 ID，沿用目標、狀態與冷卻規則；施放時免學習、免 MP／HP／材料費，失敗不消耗卷軸，結束即復原技能資料。
- **開箱**：只保留可用的獎勵，保留有資料的最小／最大數量。未公告隨機權重的來源採本作等機率，`omittedContents` 保留被排除的獎勵 ID；不匯入未存在的系統物品。22 小時可重開的容器以同 ID 共用冷卻，存在角色存檔。

死亡、絕對屏障、鎖定、職業及來源等級條件會阻擋自訂消耗品；失敗不扣物品。一般回城與瞬移依原函式保留受控、裂痕、排名及特殊區域限制。

## 來源數值與本作適配的界線

**保留的事實**：大小型傷害、AC、六維屬性、回血回魔、MR／屬性抗性、來源列出的觸發率、可對應的技能、強化門檻、已公告補量及時效、可核對的材料及產量。

**本作決策**：商店定價、工資、掉落機率、材料提煉、刻寫卷軸、失去氣息物品的確定復原、裂痕戰勳、未公布權重的等機率開箱、限時活動裝備改為永久保存、魔法娃娃使用本作既有永久裝備欄。

來源只寫吸魔而沒有數字時採本作同類武器的每次命中 3 MP；只寫吸血而沒有數字時採傷害量 5%，逐件記在 `ttmiAdaptation`。武器種類的連擊、連射等採本作既有類型機制，不宣稱是原版隱藏機率。

既有同名物品保留專案的平衡，不為了對齊新來源覆寫數值。27 件傲慢之塔符印／卷軸，依來源敘述的真實目的樓層對齊舊塔 ID：例如來源名「2樓」，內文卻是 11 樓，便對應專案的 11F 物品；沒有另外製造一個用途不明的新符印。

### 經濟及掉落預算

新裝備以傷害、AC、主要屬性、命中、HP／MP 等數值換算定價。商店價格為裝備定價的 10 倍、材料 5 倍、其他消耗品 3 倍；箭矢採獨立的小額單價。這是本作的初始平衡數字，可在產生器調整。

容器售價至少高於其最高單次獎勵的定價換算值 25%；固定全給的箱子則計全部獎勵，巢狀箱逐層計算。這裡的換算值也涵蓋既有獎品，不表示那些獎品必然在古物商人販售。工坊的工資下限保護「製成後直接回售」；若成品是容器，開啟後的價值須另外檢查。

新增掉落對每一種怪物設固定預算：一般怪物合計 **8 個百分點**，首領合計 **20 個百分點**，再依材料／補給／裝備的 5／3／1 權重分配。這是原生各項獨立掉落率的總和，表示額外掉落件數期望值約 0.08／0.20；不是「至少一件」的精確機率。原有幸運、模式等掉落倍率照既有流程處理。新物品全部 `gachaWeight:0`，不擴充既有抽獎池。

這些預算限制額外掉落與金幣來源；尚未用真實長期玩家存檔量測每小時金幣、各等級取得速度及完整角色 DPS。實裝回歸通過不等於已完成長期經濟調校。

### 893 條配方與容器的現金循環核對

本次以原生資料、原生回售函式及 `corrupt → ttmi-items` 的實際登錄順序做靜態試算，沒有重新執行瀏覽器或讀寫玩家存檔。完整逐配方與逐容器結果見 [經濟核對資料](../data/ttmi-economy-audit.json)；可用 `node scripts/audit-ttmi-economy.mjs --write-report` 重建。

原生白字回售為 `floor(定價 ×0.3)`。屬性、祝福、遠古詞綴可各自使原生回售乘 10，但古物商店、材料工坊與本擴充容器都強制產出普通物品，因此這三條取得途徑不會抽中詞綴售價倍率。不可出售的獎品在可實現的現金收益中計 0。

| 檢查範圍 | 結果 | 可以支持的結論 |
| --- | --- | --- |
| 全部 893 條配方的現金需求與成品直接回售 | 881 條現金需求較高；12 條現金需求與回售皆為 0；沒有現金需求較低的配方 | 即使先忽略原料成本，直接製成後回售也沒有正收益；12 條零售價配方仍會消耗原料 |
| 421 條材料提煉 | 每次另花 100 金幣，魔法結晶體回售 30 金幣 | 未計原料已虧 70 金幣，不依賴 37.5% 下限也成立 |
| 古物商店的 2,208 種商品 | 買入後直接回售均無正收益 | 不包含其他 NPC 的收購委託價格 |
| 可購買的 217 種新容器 | 單次開啟的期望值與最高獎勵均不能回本 | 遞迴計算新容器與固定兌換；可重開容器連同本體立即賣回也不能回本 |
| 78 條製作新容器的配方 | 14 條可由已核對商店與這 893 條確定合成配方取得全部原料；這 14 條即使抽到最高獎勵也不能回本 | 原料成本採有利於買方的下限，包括一般商店的攻城八折及可分攤的批次成本；實際限制只會增加成本 |
| 既有魔法娃娃袋的新增製法 | 材料購得成本下限為 2,000 金幣；14 種原生獎品均不可出售 | 開袋沒有直接現金回報；娃娃收藏、合成進度的價值未換算成金幣 |

**下限的邊界：**78 條製箱配方中，有 71 條開箱後可回收的金幣期望高於單看工資的金額（可重開者包含本體賣回）；這不等於可以套利，因為原料會消耗。其餘 64 條沒有在本次「商店＋893 條確定配方」建立完整買料路徑，仍依賴掉落或其他來源，不能假設原料免費，也不能據此宣布那些路徑已全部排除套利。兩種沿用原生邏輯的上鎖寶箱還會消耗龜裂之核，沒有在這次核對範圍內建立純購買循環。

其他 NPC 製作、隨機箱取得原料後再合成、收購委託、詞綴轉換、掉落倍率與長期玩家金幣流量，不在這次靜態證明之內。本次沒有發現已核對路徑的立即可重複正收益，因此沒有另外調整售價或製作費用。
