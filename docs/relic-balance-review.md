# 遺物平衡實測與驗證範圍

本檔整理**遊戲規則、實測結果與平衡判斷**；逐件遺物的設計理念與各階效果另見 [遺物設計目錄](relic-design-catalog.md)。完整逐案數據保存在 [relic-balance-results.json](relic-balance-results.json)，真反射死亡的追加診斷保存在 [relic-balance-fatal-reflection.json](relic-balance-fatal-reflection.json)。

測試日期：2026-10-22 UTC。這是包含 #51 強化版本原生強制變身、卡片戰鬥掛點與首領跨階段身分繼承修正之後，重新跑完的 68 場戰鬥矩陣快照；以下數字取代修正前的測試結果。

## 結論與適用範圍

本輪以固定種子 `20261022` 完成 **68 場原生戰鬥：37 場通關、21 場倒下、10 場超時**。沒有例外拋出、頁面錯誤或生命／魔力／出手間隔的非有限值。這份**戰鬥矩陣快照**的全部 **54 個追蹤來源檔案**在每場前後與整批前後維持同一雜湊，包含全部 `js/NN` 核心、卡片四模組、遺物模組與相關傷害掛點；這項紀錄不表示後續版本的每個位元組都與快照相同。

在這組合法配裝中，Lv100 的 #51 四個階段都能通過指定塔王；終階將塔王戰縮短到約16–18秒。四龍仍有明顯生存與長戰門檻：低階單人大多無法承受房間傷害，部分轉生單人能活到時間上限，但無法在首領回復前完成後期階段；完整16人隊伍則約80–83秒完成七階。

**本輪確實有1場反射死亡**：Lv100 終階 #51 在林德拜爾第4階、104.1秒，剩餘13.52%生命時被反射收尾。追加重播確認當時魔法專用護盾不適用該次近戰反射，免死尚餘9.6秒冷卻。它與滿血單擊致死、反射事件無限重入是不同情形，不能統稱為同一個問題。其餘死亡為14場環境傷害、6場治癒反噬。

這是固定配裝與單一種子的可重現紀錄，不是勝率統計或全遺物最佳配裝搜尋。角色**未主動選用變身、卡片或娃娃；裝備自帶的原生強制變身照常生效**。新增鑽石變身的首擊倍率與自然反射窗另有 [卡片反射測試資料](card-reflection-results.json)，不混入這組基準。

## 測試方法

- 每場使用新的瀏覽器環境。角色以合法創角點數、升級點數與轉生保留能力建立，再交由原生 `recomputeStats` 計算。
- 使用原生 `tick()`，每 tick 推進0.1遊戲秒。出怪、技能、藥水、死亡、反射、首領變身與七階龍戰均經目前專案的原生流程。
- 傲慢100樓指定死神（65,000 HP）；支配10樓指定烏格奴斯 `afk_ttmi_220`（70,277 HP）。四龍從最終房開始，保留完整七階，不以低生命小怪替代首領。
- Lv100 騎士使用遺物 #51，分別測 +5、+10、昇華支配、昇華支配+5；Lv150 轉生角色測 #100 近戰、#41 弓、#129 法師、#33 幻術。防具與武器同階，依職業配置，雙手武器不配盾。
- 比較配裝使用 #134 襯衫、#151 斗篷、#220 頭盔、#205 鞋、#190 護脛、#227／#229 戒指、#233 耳環、#240 腰帶。盔甲／手套／項鍊依職業調整；完整槽位、品名、初始能力與技能數均在 JSON。
- 白色治療藥水起始100瓶，原生自動補貨至100瓶；藥水門檻75%、治療門檻70%。使用原生加速／職業／藍色藥水；法師自動施放龍捲風。技能依職業與等級資格學習，沒有額外指定無敵狀態。
- 16人隊伍由1名騎士隊長、3名騎士、4名妖精、4名法師、4名幻術士組成。15名隊友使用原生 `buildAlly` 建立。
- 兩塔每場最多180秒；龍戰每場最多300秒。HP觀測器記錄實際扣血與回復，超額傷害不灌入有效DPS。總場景DPS含小怪；`bossNetDps` 只計首領淨損血。所有通關時間均是遊戲時間。

強化／昇華版本現在會以原始遺物身分判定冥皇執行劍的原生強制變身。修正前，衍生 ID 沒有通過原生武器比對，這會低估 #51 的速度與整體表現；因此舊的 +5 塔王超時、終階安塔瑞斯超時數字不可繼續使用。這是功能接合修正帶來的差異，不是效能快取改變傷害。

目前終階相較昇華支配，兩塔通關時間約縮短至三分之一，顯示終階有明顯戰力躍升。終階單挑安塔瑞斯雖於265.5秒通過，最低生命只有278.19，屬於低餘裕的長戰；同套配置對另外三龍仍倒下，不能據此宣稱穩定單挑四龍。

低階龍戰瓶頸首先是生存。房間每秒傷害包含500點真實部分與500點元素部分，元素部分沿用既有抗性／弱勢倍率；這種傷害屬環境 DOT，許多只針對直接攻擊的減免不適用。防護現在會接到原生受傷流程，仍須符合各遺物自己的條件。

### 倒下原因

| 原生死亡來源 | 場數 | 本輪情形 |
|---|---:|---|

## GM99999 與 GM99998

兩件皆直接固定在昇華支配+5，分開測試，沒有升級流程。一般出手時，兩塔均於0.1秒擊倒指定首領，四龍均以70.7秒完成七階。每次GM攻擊是有限的131個武器來源段，並套用其他遺物被動；GM防具另啟用全部套裝。

正常GM輸出往往在反射啟動前便把該階打入鎖血，因此額外採原生換裝測反射：先穿普通終階配裝，等首領自然展開魔法反射，再用 `unequipItem`／`equipItem` 換上指定GM裝備。沒有在換裝時補滿當前生命；換裝前後HP與實際槽位均有記錄。

## 找到並修正的事件問題

1. **代傷被誤認為敵方攻擊，造成自傷反擊循環。** GM召喚物受擊時，#186塔盾把部分傷害轉給主人；原流程遺失 `redirected/noProc`，又把主人當成攻擊者，#191與#214因此對自己反擊。修正保留代傷來源及旗標，自傷不產生敵方反擊目標，代傷不再次分攤；護盾、治療與免死仍按條件運作。回歸見 [test-relic-reactions.mjs](../scripts/test-relic-reactions.mjs)。
2. **龍房傷害與治癒反噬直接扣HP，漏過遺物防護。** 房間脈衝、死亡藥水、死亡治療現在先走受傷流程，再扣HP與判定死亡；原生傷害量與詛咒規則仍照原計算。
3. **#26 原稿的−100%攻速使出手間隔除以0。** 經確認改用本件專屬間隔倍率：+5為2倍、+10及昇華階段為3倍，文字與計算一致。其他遺物的攻速設定沿用各自設計。
4. **原生施法與傭兵分支漏過遺物來源。** 補齊來源倍率、免費法術反射、主體扣HP前掛點與逐件治癒冷卻；傭兵防具反擊法術倍率只套一次。回歸涵蓋131件武器終階原生通道及玩家／傭兵反射。
5. **#51 強化版本漏掉原生強制變身。** 原生判斷只比對基礎武器 ID，現在衍生版本先還原 `relicBase` 再比對；裝備、卸裝與卡片變身優先序已有原生回歸。最終矩陣已全數重跑。
6. **卡片首擊資格在首領變身後重置。** 首領跨階段延續同一個目標識別，避免把同一首領的下一階再次當成首次攻擊。此掛點已納入本輪來源指紋；啟用卡片後的傷害驗證另見 [卡片戰鬥測試](card-combat-results.json)。

## 平衡判斷與待決策方向

- **階段差距需分開看。** #51 從+5到終階，塔王通關速度與生存餘裕都明顯上升；終階的表現不能代表較低階也應單挑龍房。比較其他遺物時，應先固定角色等級與相同階段。
- **單人與16人隊伍要設定不同目標。** 單人仍有生存／首領回滿的門檻，16人已接近70秒鎖血底限。若決定調整四龍，應先確定預期隊伍規模，再討論血量、環境壓力或輸出。
- **屠龍特化會略過反射節奏。** #100能在首個反射窗前壓入鎖血，GM更能在0.1秒完成可輸出部分。反射評估必須記錄實際是否接觸反射，不能只看成功通關。
- **自動戰鬥策略是獨立決策。** 可以考慮在同類反射窗暫停相應攻擊，以及在死亡藥水／死亡治療期間暫停對應恢復來源；這會改變玩法與輸出節奏，目前未擅自加入，也未增加反射免疫來消除測試死亡。
- **玩家需要辨識防護範圍與冷卻。** 魔法護盾不擋近戰反射；免死30秒冷卻與遺物治癒共用門檻也不同。應從物品／狀態說明清楚看懂，避免有護盾仍倒下被誤認為機制失效。
- **效能採獨立證據。** 本矩陣 `wallSeconds` 含角色設定、觀測器與模擬，不當作FPS測試。來源快取、GM派發與前景效能的正式 A/B，以及保留全部事件的驗證，另見 [效能檢討](performance-review.md)。
